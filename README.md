## ⚡ How to Deploy to Vercel

### Method 1: Using the Vercel Dashboard (Zero Config)
1. Push this folder to your GitHub repository (e.g., `github.com/lihash2007/portfolio`).
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** &rarr; **"Project"**.
4. Select your `portfolio` repository from the list.
5. Keep the default settings (Framework Preset: **Other**; Root Directory: `./`).
6. Click **"Deploy"**! Your portfolio will be live at `https://<your-project>.vercel.app` in under 30 seconds.

### Method 2: Using Vercel CLI
```bash
# Install Vercel CLI globally
npm install -g vercel

# Deploy from project directory
vercel
```
